# Plan 05-01: Google Form DOM Reader & Content Script Implementation

## Objective

Update extension Manifest V3 configuration to include content script matching `https://docs.google.com/forms/*`, build `domReader.ts` for parsing text inputs and headings from Google Form DOM containers, and implement `contentScript.ts` message listener responding to `'SCAN_FIELDS'`.

## Artifacts this phase produces

### New files
- `extension/src/content/domReader.ts` — DOM traversal & `FieldMetadata` extraction logic
- `extension/src/content/contentScript.ts` — Content script entry point registering `chrome.runtime.onMessage` listener

### Modified files
- `extension/src/manifest.ts` — Add `content_scripts` declaration matching Google Forms URLs

<task id="05-01-T2">
<title>Implement Google Form DOM reader module</title>
<read_first>
- shared/src/index.ts
- .planning/phases/05-content-script-google-form-dom-reader/05-CONTEXT.md
</read_first>
<action>
Create `extension/src/content/domReader.ts`:
- Export function `extractFormFields(doc: Document = document): FieldMetadata[]`.
- Queries list items (`[role="listitem"]`, `.freebirdFormviewerViewItemsItemItem`, or item blocks).
- Finds text inputs (`input[type="text"]`, `input[type="email"]`, `input[type="tel"]`, `input:not([type])`, `textarea`).
- Extracts `id` (`name` attribute or `id` or fallback `field-index`).
- Extracts `label` from closest heading (`[role="heading"]`, `.freebirdFormviewerViewItemsItemItemTitle`, `<label>`), fallback `aria-label` or `placeholder`.
- Extracts `placeholder`, `ariaLabel`, `type`, and `required`.
</action>
<acceptance_criteria>
- `extension/src/content/domReader.ts` exports `extractFormFields`.
- Parses text inputs and textareas into valid `FieldMetadata` objects.
</acceptance_criteria>
</task>

<task id="05-01-T3">
<title>Implement content script entry point and message listener</title>
<read_first>
- extension/src/content/domReader.ts
</read_first>
<action>
Create `extension/src/content/contentScript.ts`:
- Import `extractFormFields` from `./domReader.js`.
- Register `chrome.runtime.onMessage.addListener((message, sender, sendResponse) => { ... })`.
- If `message.action === 'SCAN_FIELDS'`, run `extractFormFields()` and respond with `{ status: 'success', fields }`.
</action>
<acceptance_criteria>
- `extension/src/content/contentScript.ts` listens for `SCAN_FIELDS` message.
- Returns `{ status: 'success', fields: FieldMetadata[] }`.
</acceptance_criteria>
</task>
