# Plan 06-01: Form Filler Module & Content Script Message Integration

## Objective

Export `FillResult` interface in `shared`, implement `formFiller.ts` with DOM element lookup, prototype value setting, event dispatching (`input`, `change`, `blur`), 2-second green outline highlight transition, and update `contentScript.ts` to handle `'FILL_FIELDS'` messages.

## Artifacts this phase produces

### Modified files
- `shared/src/index.ts` — Export `FillResult` interface
- `extension/src/content/contentScript.ts` — Add `'FILL_FIELDS'` message handler

### New files
- `extension/src/content/formFiller.ts` — DOM value injection, event dispatching, and visual highlight logic

## Tasks

<task id="06-01-T1">
<title>Export FillResult interface in shared package</title>
<read_first>

</read_first>
<action>
Update `shared/src/index.ts`:
- Export interface `FillResult`:
  - `status: 'success' | 'partial' | 'error'`
  - `filledCount: number`
  - `failedCount: number`
  - `filledFields: string[]`
  - `failedFields: string[]`
  - `error?: string`
</action>

<task id="06-01-T2">
<title>Implement formFiller DOM injection module</title>
<read_first>
- extension/src/content/domReader.ts
- .planning/phases/06-content-script-form-filler/06-CONTEXT.md
</read_first>
<action>
Create `extension/src/content/formFiller.ts`:
- Export function `fillFormFields(mappings: Record<string, string>, doc: Document = document): FillResult`.
- For each entry `[fieldId, value]` in `mappings`:
  - Locate element by `name="${fieldId}"`, `id="${fieldId}"`, or `[aria-describedby*="${fieldId}"]`.
  - Use native setter (`HTMLInputElement.prototype` or `HTMLTextAreaElement.prototype` setter) to ensure framework state updates.
  - Dispatch `Event('input', { bubbles: true })`, `Event('change', { bubbles: true })`, `Event('blur', { bubbles: true })`.
  - Apply visual green border/outline highlight for 2000ms.
  - Track `filledFields` and `failedFields`.
- Return structured `FillResult`.
</action>
<acceptance_criteria>
- `formFiller.ts` exports `fillFormFields`.
- Injects values, dispatches events, and highlights filled elements.
- Returns accurate `FillResult`.
</acceptance_criteria>
</task>

<task id="06-01-T3">
<title>Integrate FILL_FIELDS message handler in contentScript.ts</title>
<read_first>
- extension/src/content/contentScript.ts
- extension/src/content/formFiller.ts
</read_first>
<action>
Update `extension/src/content/contentScript.ts`:
- Import `fillFormFields` from `./formFiller.js`.
- In `chrome.runtime.onMessage` listener:
  - If `message?.action === 'FILL_FIELDS'`, call `fillFormFields(message.mappings || {})` and return `{ status: 'success', result }`.
</action>

- Responds with fill results.
