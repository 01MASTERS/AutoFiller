# Plan 24-02: Dynamic Option Probing & Mutation Settlement Engine

## Objective

Build an asynchronous mutation settlement and dynamic option extraction engine (`dynamicOptionSettler.ts`) capable of monitoring DOM mutations, awaiting backend options arriving via AJAX/REST fetches, observing reactive enablement of cascading fields, and dynamically extracting live options from custom listboxes, portaled popovers, and native selects at fill time.

## Artifacts this plan produces

### New Files
- `extension/src/content/domReader/dynamicOptionSettler.ts` — Engine providing `waitForDynamicOptions()`, `waitForFieldEnabled()`, and `extractLiveOptions()`.
- `extension/src/__tests__/dynamicOptionSettler.test.ts` — Comprehensive unit test suite verifying MutationObserver detection of asynchronously appended `<option>` tags, ARIA `role="option"` elements, attribute changes (`aria-busy`), disabled removals, and timeout safety.

### Modified Files
- `extension/src/content/domReader/optionParser.ts` — Export helper to re-extract options from any live container or popup portal.
- `extension/src/content/domReader/index.ts` — Re-export dynamic settlement utilities for use by form filler and adapters.

## Detailed Tasks

### Task 1: Dynamic Option Settlement Engine
1. Create `extension/src/content/domReader/dynamicOptionSettler.ts`:
   - Implement `waitForDynamicOptions(container: Element, timeoutMs = 1200): Promise<FieldOption[]>`:
     - Check if options already exist in `container` or its associated popup (`aria-controls`, `aria-owns`, `.OA0qNb`, `[role="listbox"]`). If $> 1$ non-placeholder options exist, return immediately.
     - Set up a `MutationObserver` listening to `childList` and `attributes` (specifically `aria-busy`, `style`, `class`) on `container` and `container.ownerDocument.body` (to capture portaled popups).
     - Debounce arrivals: when new `option` or `[role="option"]` nodes are added and `aria-busy !== 'true'`, extract options via `extractSelectOptions` or `extractAriaListboxOptions`.
     - Reject or resolve with current available options when `timeoutMs` expires (with test environment acceleration: `isTest ? 40ms : timeoutMs`).
   - Implement `waitForFieldEnabled(element: Element, timeoutMs = 1200): Promise<boolean>`:
     - Check if element is already enabled (`!element.disabled` and `aria-disabled !== 'true'`). If so, return `true`.
     - Set up `MutationObserver` on `attributes: ['disabled', 'aria-disabled']` to resolve as soon as the attribute is removed or set to `'false'`.
     - Safety timeout fallback returning current status.
   - Implement `extractLiveOptions(field: FieldMetadata, element: Element, doc: Document): FieldOption[]`:
     - Re-evaluates live options on the element or its associated portal popup at runtime, updating `field.options` and `field.optionsLoaded = true`.

### Task 2: Option Parser Integration
1. In `extension/src/content/domReader/optionParser.ts`:
   - Add `extractOptionsFromAny(container: Element): FieldOption[]`:
     - Dispatches to `extractSelectOptions` if `<select>`, or `extractAriaListboxOptions` if listbox/combobox/portal.

### Task 3: Export in domReader
1. In `extension/src/content/domReader/index.ts`:
   - Export `waitForDynamicOptions`, `waitForFieldEnabled`, and `extractLiveOptions`.

### Task 4: Unit Test Suite
- Create `extension/src/__tests__/dynamicOptionSettler.test.ts`:
  - Test `waitForDynamicOptions` resolves when `<option>` elements are added asynchronously via `setTimeout`.
  - Test `waitForDynamicOptions` resolves when ARIA `[role="option"]` nodes appear inside an `aria-controls` target.
  - Test `waitForDynamicOptions` waits for `aria-busy="true"` to flip to `"false"`.
  - Test timeout safety: gracefully returns available options without throwing unhandled exceptions if the backend never responds.
  - Test `waitForFieldEnabled` resolves when a disabled select has its `disabled` attribute removed.

## Verification Criteria
- [ ] All unit tests in `dynamicOptionSettler.test.ts` pass.
- [ ] Timeout handles zero-response edge cases gracefully without freezing.
