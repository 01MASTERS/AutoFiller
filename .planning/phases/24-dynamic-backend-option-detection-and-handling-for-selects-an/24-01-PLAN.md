# Plan 24-01: Shared Schema Extensions & Static vs. Dynamic Option Classification

## Objective

Extend `@autofiller/shared` types to express option loading characteristics (`optionSource`, `optionsLoaded`, `parentFieldId`, `dynamicState`), and implement a multi-tier heuristic classifier in `extension/src/content/domReader/` that inspects DOM controls (selects, ARIA comboboxes, and MCQ groups) to reliably distinguish static/hardcoded options from backend-fetched options and identify cascading parent-child dependencies.

## Artifacts this plan produces

### New Files
- `extension/src/__tests__/dynamicOptionDetection.test.ts` — Comprehensive unit test suite verifying classification of static selects, async/backend dropdowns, placeholder-only selects, remote comboboxes, and cascading country/state pairs.

### Modified Files
- `shared/src/index.ts` — Add `OptionSource = 'static' | 'dynamic' | 'cascading'`, `parentFieldId?: string`, `optionsLoaded?: boolean`, and `dynamicState` to `FieldMetadata`.
- `extension/src/content/domReader/utils.ts` — Add helper functions `hasRemoteDataAttributes(element)` and `isAsyncCombobox(element)`.
- `extension/src/content/domReader/optionParser.ts` — Add `detectOptionSource(element, options, container)` to classify fields based on option counts, placeholder filtering, `aria-busy`, and remote data attributes.
- `extension/src/content/domReader/controls/dropdown.ts` — Apply `detectOptionSource` during select/combobox scanning and populate `optionSource` and `optionsLoaded`.
- `extension/src/content/domReader/fieldDiscovery.ts` — Add a post-scan cascading dependency linking pass (`linkCascadingFields(fields)`) that connects dependent fields (e.g. State) to upstream parent fields (e.g. Country).

## Detailed Tasks

### Task 1: Shared Type Definitions
1. In `shared/src/index.ts`, define:
   ```ts
   export type OptionSource = 'static' | 'dynamic' | 'cascading';

   export interface DynamicOptionState {
     isAsync?: boolean;
     requiresInputToSearch?: boolean;
     endpointUrl?: string;
   }
   ```
2. Extend `FieldMetadata`:
   ```ts
   export interface FieldMetadata {
     // ... existing fields ...
     optionSource?: OptionSource;
     parentFieldId?: string;
     optionsLoaded?: boolean;
     dynamicState?: DynamicOptionState;
   }
   ```

### Task 2: Heuristic Detection in DOM Reader
1. In `extension/src/content/domReader/utils.ts`:
   - Implement `hasRemoteDataAttributes(el: Element): boolean`:
     - Checks `data-source`, `data-remote`, `data-url`, `data-endpoint`, `data-ajax`, `[data-automation-id*="prompt"]`, or classes `select2-ajax`, `chosen-ajax`, `async-select`, `is-loading`.
   - Implement `isAsyncCombobox(el: Element): boolean`:
     - Checks `role="combobox"` with `aria-autocomplete="list"` or `aria-autocomplete="both"`.
2. In `extension/src/content/domReader/optionParser.ts`:
   - Implement `detectOptionSource(el: Element, options: FieldOption[] | undefined, container?: Element): { optionSource: OptionSource; optionsLoaded: boolean }`:
     - If `options` has $> 1$ valid non-placeholder options and no `aria-busy="true"` $\to$ `{ optionSource: 'static', optionsLoaded: true }`.
     - If options count is $0$, or only $1$ placeholder option exists, or `aria-busy="true"`, or `hasRemoteDataAttributes(el)` is true, or `isAsyncCombobox(el)` with empty list $\to$ `{ optionSource: 'dynamic', optionsLoaded: false }`.
3. In `extension/src/content/domReader/controls/dropdown.ts`:
   - When creating `FieldMetadata` for dropdown or combobox, invoke `detectOptionSource` to populate `field.optionSource` and `field.optionsLoaded`.
4. In `extension/src/content/domReader/fieldDiscovery.ts`:
   - Implement `linkCascadingFields(fields: FieldMetadata[]): void`:
     - Inspect fields for common relational pairs:
       - Upstream: label or name matches `/country/i`
       - Downstream: label or name matches `/state|province|region|territory/i`
     - If the downstream field is dynamic, empty, or disabled, set `downstreamField.optionSource = 'cascading'` and `downstreamField.parentFieldId = upstreamField.id`.

### Task 3: Unit Tests
- Create `extension/src/__tests__/dynamicOptionDetection.test.ts`:
  - Test static `<select>` with multiple options $\to$ `optionSource: 'static'`, `optionsLoaded: true`.
  - Test empty `<select>` with only `<option value="">Select country...</option>` $\to$ `optionSource: 'dynamic'`, `optionsLoaded: false`.
  - Test ARIA combobox with `aria-autocomplete="list"` and no options $\to$ `optionSource: 'dynamic'`.
  - Test element with `data-url="/api/options"` $\to$ `optionSource: 'dynamic'`.
  - Test paired Country and State fields $\to$ State field has `optionSource: 'cascading'` and `parentFieldId: country.id`.
