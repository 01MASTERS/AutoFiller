# Plan 24-03: Dependency-Aware Topological Form Filling & JIT Resolution

## Objective

Implement dependency-aware topological ordering and Just-in-Time (JIT) option matching during form fill execution. Ensure upstream trigger fields (such as Country) are filled and settled first, triggering reactive frontend events so backend APIs can populate downstream cascading fields (such as State/Province). Provide searchable combobox typing simulation for remote typeaheads, and build an interactive mock fixture (`/test-forms/dynamic-options`) with automated Vitest E2E verification.

## Artifacts this plan produces

### New Files
- `extension/src/__tests__/dynamicFormsFiller.test.ts` — Unit tests for topological sort, cascading wait, and JIT option selection on async dropdowns.
- `backend/src/__tests__/dynamicFormsE2E.test.ts` — Integration tests validating the `/test-forms/dynamic-options` endpoint and simulated fill cycles.

### Modified Files
- `extension/src/content/formFiller/index.ts`:
  - Implement `orderFieldsTopologically(mappings, fields)` to sort execution order so parent fields precede children.
  - Integrate post-fill cascading wait: after filling an upstream parent field, wait for dependent child fields to enable and populate options via `waitForFieldEnabled` and `waitForDynamicOptions`.
- `extension/src/content/formFiller/simulators/selectSimulator.ts`:
  - In `fillNativeDropdown`: if options are empty or placeholder-only, await `waitForDynamicOptions` before attempting value match.
  - In `fillAriaDropdown`: if options are not rendered upon opening, await `waitForDynamicOptions`; for search-required comboboxes, type the mapped search query into the search input and wait for filtered options to mount.
- `shared/src/fixtures/mockForms.ts`:
  - Add `dynamicOptionsFormHtml` featuring:
    1. Async Country dropdown (options populated via simulated fetch with 100ms delay).
    2. Cascading State dropdown (initially disabled; enables and loads states when Country is selected).
    3. Remote searchable combobox (University / Job Title) that populates options on search input.
- `backend/src/routes/api.ts`:
  - Serve `dynamicOptionsFormHtml` at `GET /test-forms/dynamic-options` and link it in the Test Forms Hub (`GET /test-forms`).

## Detailed Tasks

### Task 1: Topological Ordering & Form Filler Orchestration
1. In `extension/src/content/formFiller/index.ts`:
   - Implement `sortFieldsByDependency(fields: FieldMetadata[], mappings: Record<string, FieldMappingValue>): string[]`:
     - Construct a directed graph where an edge exists from `field.parentFieldId` to `field.id`.
     - Perform topological sort (Kahn's algorithm or DFS with cycle protection) to produce an ordered sequence of field IDs.
     - Append unconstrained fields preserving their visual DOM order.
   - Update `fillFormFields()`:
     - Iterate through fields in topological order.
     - After successfully filling any field that is referenced as `parentFieldId` by a downstream field:
       - Find dependent child elements.
       - Await `waitForFieldEnabled(childEl)` and `waitForDynamicOptions(childEl)`.

### Task 2: JIT Option Settlement in Control Simulators
1. In `extension/src/content/formFiller/simulators/selectSimulator.ts`:
   - In `fillNativeDropdown`:
     - If `selectEl.options.length <= 1`, await `waitForDynamicOptions(selectEl)`.
     - Re-run option matching against newly populated options.
   - In `fillAriaDropdown`:
     - After opening the popup, if options count is 0 or `aria-busy="true"`, await `waitForDynamicOptions(listbox)`.
     - If the combobox has a search input and options require typing to filter, simulate typing the desired value, wait for option nodes to appear, and click the matched option.

### Task 3: Interactive Mock Fixture & Backend Registration
1. In `shared/src/fixtures/mockForms.ts`:
   - Add `dynamicOptionsFormHtml` containing realistic simulation:
     - Phone Country code dropdown (`<select id="country-code">`) loaded via async timeout.
     - Cascading `country-select` and `state-select` where `state-select` is disabled until `country-select` dispatches `change`.
     - Searchable combobox `[role="combobox"]` with remote options.
2. In `backend/src/routes/api.ts`:
   - Register `GET /test-forms/dynamic-options`.
   - Update `GET /test-forms` index to include the Dynamic Options test page.

### Task 4: Automated Testing
1. Create `extension/src/__tests__/dynamicFormsFiller.test.ts`:
   - Test topological ordering: given State before Country in mapping keys, Country is filled first, followed by State.
   - Test fillNativeDropdown waits for options arriving via async delay.
   - Test fillAriaDropdown handles search input typing and option click.
2. Create `backend/src/__tests__/dynamicFormsE2E.test.ts`:
   - Test `GET /test-forms/dynamic-options` returns 200 OK with expected DOM elements and script tags.
