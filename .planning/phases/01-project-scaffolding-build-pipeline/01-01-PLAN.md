# Plan 01-01: Tracer — Monorepo + Extension + Backend Skeleton

## Objective

Create the thinnest end-to-end working slice: a root monorepo with npm workspaces linking `extension/`, `backend/`, and `shared/` packages. The extension loads in Chrome (MV3) with a minimal popup. The backend starts and serves `GET /health`. `npm run dev` launches both via `concurrently`.

## Artifacts this phase produces

### New files
- `package.json` — Root monorepo package.json with npm workspaces config
- `extension/package.json` — Extension package with Vite + CRXJS dependencies
- `extension/vite.config.ts` — Vite config with `@crxjs/vite-plugin` for MV3
- `extension/tsconfig.json` — TypeScript config (strict mode)
- `extension/src/manifest.ts` — Chrome MV3 manifest using CRXJS typed manifest
- `extension/src/popup/popup.html` — Minimal popup HTML
- `extension/src/popup/popup.ts` — Minimal popup TypeScript entry
- `backend/package.json` — Backend package with Express + tsx dependencies
- `backend/src/index.ts` — Express server with `/health` endpoint
- `backend/tsconfig.json` — TypeScript config (strict mode)
- `shared/package.json` — Shared types package
- `shared/src/index.ts` — Shared types barrel export
- `shared/tsconfig.json` — TypeScript config (strict mode)

### New symbols
- `backend/src/index.ts`: Express app, `/health` route handler, `PORT` const
- `shared/src/index.ts`: placeholder type exports
