# Plan 01-02: Code Quality — ESLint + Prettier + Shared Config

## Objective

Set up ESLint and Prettier across the monorepo with a shared root config. Both `extension/` and `backend/` inherit the root config. `npm run lint` runs ESLint on all source files. All existing files pass lint and format checks.

## Artifacts this phase produces

### New files
- `.eslintrc.cjs` — Root ESLint config (TypeScript parser, recommended rules)
- `.prettierrc` — Prettier config (consistent formatting)
- `.prettierignore` — Prettier ignore patterns (dist/, node_modules/, etc.)

### Modified files
- `package.json` — Add ESLint + Prettier devDependencies, format script
- `extension/package.json` — Update lint script to use root config
- `backend/package.json` — Update lint script to use root config

### New symbols
- None (configuration only)

## Tasks

<task id="01-02-T1">
<title>Create root ESLint configuration for TypeScript</title>
<read_first>
- package.json
- extension/tsconfig.json
- backend/tsconfig.json
</read_first>
<action>
Create `.eslintrc.cjs` at project root:
- parser: `@typescript-eslint/parser`
- plugins: `@typescript-eslint`
- extends: `eslint:recommended`, `plugin:@typescript-eslint/recommended`
- parserOptions: project references to `extension/tsconfig.json`, `backend/tsconfig.json`, `shared/tsconfig.json`
- rules: customize `@typescript-eslint/no-unused-vars` to warn (with argsIgnorePattern `^_`), `@typescript-eslint/explicit-function-return-type` off
- ignorePatterns: `dist/`, `node_modules/`, `*.js` (allow .cjs config)

Add to root `package.json` devDependencies:
- `eslint` (latest 8.x — ESLint 9 flat config is not yet stable with all plugins)
- `@typescript-eslint/parser` (latest)
- `@typescript-eslint/eslint-plugin` (latest)

Update root `package.json` scripts:
- `lint`: `eslint "extension/src/**/*.ts" "backend/src/**/*.ts" "shared/src/**/*.ts"`
</action>
<acceptance_criteria>
- `.eslintrc.cjs` exists at project root
- `.eslintrc.cjs` contains `@typescript-eslint/parser`
- `package.json` has `eslint`, `@typescript-eslint/parser`, `@typescript-eslint/eslint-plugin` in devDependencies
- `npm run lint` exits 0 on all existing source files
</acceptance_criteria>
</task>

<task id="01-02-T2">
<title>Create Prettier configuration</title>
<read_first>
- package.json
- .eslintrc.cjs
</read_first>
<action>
Create `.prettierrc` at project root:
- `semi`: true
- `singleQuote`: true
- `trailingComma`: "all"
- `printWidth`: 100
- `tabWidth`: 2
- `arrowParens`: "always"

Create `.prettierignore`:
- `dist/`
- `node_modules/`
- `*.md`
- `package-lock.json`

Add to root `package.json` devDependencies:
- `prettier` (latest)
- `eslint-config-prettier` (latest)

Update `.eslintrc.cjs` extends to include `prettier` at the end (disables formatting rules that conflict).

Add to root `package.json` scripts:
- `format`: `prettier --write "extension/src/**/*.ts" "backend/src/**/*.ts" "shared/src/**/*.ts"`
- `format:check`: `prettier --check "extension/src/**/*.ts" "backend/src/**/*.ts" "shared/src/**/*.ts"`
</action>
<acceptance_criteria>
- `.prettierrc` exists with `singleQuote: true` and `semi: true`
- `.prettierignore` exists with `dist/` and `node_modules/`
- `package.json` has `prettier` and `eslint-config-prettier` in devDependencies
- `.eslintrc.cjs` extends array ends with `"prettier"`
- `npm run format:check` exits 0 on all existing source files
</acceptance_criteria>
</task>
