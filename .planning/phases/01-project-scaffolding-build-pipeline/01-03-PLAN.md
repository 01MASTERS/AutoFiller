## AutoFiller
> Auto-fill Google Forms using AI-powered field matching.

### Features
- Chrome extension (Manifest V3) with popup UI
- LLM-powered field matching (Ollama local + Gemini cloud)
- Local backend server for profile storage + LLM gateway

### Architecture
- ASCII diagram from PROJECT.md (extension → backend → LLM)

### Prerequisites
- Node.js 20 LTS
- npm 9+
- Chrome 120+
- Ollama (optional, for local LLM)

### Quick Start
```bash
git clone https://github.com/01MASTERS/AutoFiller.git
cd AutoFiller
npm install
npm run dev
```

### Development
- `npm run dev` — Start backend + watch extension (concurrently)
- `npm run build` — Production build
- `npm run test` — Run all tests
- `npm run lint` — Lint all source files
- `npm run format` — Format all source files

### Loading the Extension
1. Run `npm run build`
2. Open `chrome://extensions`
3. Enable "Developer mode"
4. Click "Load unpacked"
5. Select `extension/dist/`

### Project Structure
```
AutoFiller/
├── extension/     # Chrome extension (Vite + CRXJS)
├── backend/       # Node.js + Express server
├── shared/        # Shared TypeScript types
└── .planning/     # Project planning artifacts
```

### License
MIT
