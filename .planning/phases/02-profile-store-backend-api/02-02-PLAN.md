# Plan 02-02: Express REST API Endpoints & CORS

## Objective

Set up Express CORS middleware restricting origins to `chrome-extension://*` and `http://localhost:*`, input validation middleware, error handling middleware, and REST API routes (`GET /health`, `GET /profile`, `POST /autofill` stub).

## Artifacts this phase produces

### New files
- `backend/src/middleware/cors.ts` — Custom CORS configuration for extension and dev origin matching
- `backend/src/middleware/errorHandler.ts` — Centralized error handler returning JSON errors (400 for validation errors, 500 for unhandled)
- `backend/src/routes/api.ts` — Express router mounting `/health`, `/profile`, and `/autofill`

### Modified files
- `backend/package.json` — Add `cors` and `@types/cors` dependencies
- `backend/src/index.ts` — Mount CORS middleware, Express JSON body parser, API routes, and error handler

### New symbols
- `backend/src/middleware/cors.ts`: `corsMiddleware`
- `backend/src/routes/api.ts`: Express router with GET `/health`, GET `/profile`, POST `/autofill`

<task id="02-02-T2">
<title>Create API router for /profile and /autofill stub</title>
<read_first>
- backend/src/services/profileStore.ts
- backend/src/types/profile.ts
- shared/src/index.ts
</read_first>
<action>
Create `backend/src/routes/api.ts`:
- Create Express Router `apiRouter`
- `GET /health` -> returns `{ status: 'ok', timestamp: string }`
- `GET /profile` -> calls `ProfileStore.getProfile()`, returns 200 with profile JSON or passes error to next()
- `POST /autofill` ->
  - Validates `req.body` against `autofillRequestSchema`
  - If invalid, returns 400 Bad Request with `{ status: 'error', error: 'Invalid request payload' }`
  - If valid, returns 200 OK with stub response `{ status: 'success', mappings: {} }`
</action>
<acceptance_criteria>
- `backend/src/routes/api.ts` exports router with `/health`, `/profile`, and `/autofill`
- `POST /autofill` validates request body using Zod schema
- `POST /autofill` with valid body returns stub `{ status: 'success', mappings: {} }`
</acceptance_criteria>
</task>
