# Plan 02-01: Shared Types & Profile Store Service

## Objective

Define full TypeScript interfaces for `UserProfile`, `FieldMetadata`, `AutofillRequest`, and `AutofillResponse` in `@autofiller/shared`. Install `zod` in `backend`, define Zod schemas for runtime validation, implement `ProfileStore` service for disk read/write with sample profile generator fallback, and provide sample `backend/profile.json`.

## Artifacts this phase produces

### New files
- `backend/src/types/profile.ts` — Zod schemas and TypeScript types for user profile validation
- `backend/src/services/profileStore.ts` — Service class/functions for reading `profile.json`, validating with Zod, and generating sample profile if missing
- `backend/profile.json` — Default sample user profile JSON on disk

### Modified files
- `shared/src/index.ts` — Export `FieldMetadata`, `AutofillRequest`, `AutofillResponse`, `UserProfile`
- `backend/package.json` — Add `zod` dependency

### New symbols
- `shared/src/index.ts`: `FieldMetadata`, `AutofillRequest`, `AutofillResponse`, `UserProfile`
- `backend/src/services/profileStore.ts`: `getProfile()`, `loadOrCreateProfile()`, `saveProfile()`
