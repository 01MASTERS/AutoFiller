# Plan 03-03: Vitest Unit Test Suite for LLM Gateway

## Objective

Create comprehensive Vitest unit tests with mocked LLM responses covering prompt building, response parsing, Ollama HTTP calls, Gemini SDK calls, malformed response retries, and timeout handling.

## Artifacts this phase produces

### New files
- `backend/src/__tests__/promptBuilder.test.ts` — Tests for prompt generation
- `backend/src/__tests__/responseParser.test.ts` — Tests for JSON extraction & markdown fence stripping
- `backend/src/__tests__/ollamaProvider.test.ts` — Mocked HTTP tests for OllamaProvider (success, connection error, invalid JSON)
- `backend/src/__tests__/geminiProvider.test.ts` — Mocked SDK tests for GeminiProvider (success, missing key, invalid JSON)
- `backend/src/__tests__/llmGateway.test.ts` — Gateway tests verifying provider selection and 2-retry loop

### Modified files
- None (test creation only)
