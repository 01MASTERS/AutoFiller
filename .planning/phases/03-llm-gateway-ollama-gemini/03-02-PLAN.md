# Plan 03-02: Ollama & Gemini Providers + Gateway Dispatcher

## Objective

Implement `OllamaProvider` calling Ollama's HTTP API (`http://localhost:11434/api/generate`), `GeminiProvider` using `@google/generative-ai`, 30s `AbortController` timeout, 2-retry loop for malformed responses, and unified `LLMGateway` factory/dispatcher.

## Artifacts this phase produces

### New files
- `backend/src/services/llm/ollamaProvider.ts` — `LLMProvider` implementation calling Ollama HTTP REST API with JSON mode
- `backend/src/services/llm/geminiProvider.ts` — `LLMProvider` implementation using `@google/generative-ai` SDK
- `backend/src/services/llm/gateway.ts` — Central `LLMGateway` class executing provider selection, 30s timeout, and 2-retry error handling

### Modified files
- None

### New symbols
- `OllamaProvider`: `mapFields()`
- `GeminiProvider`: `mapFields()`
- `LLMGateway`: `mapFields(providerName, fields, profile, options)`

Create `backend/src/services/llm/ollamaProvider.ts`:
- Implements `LLMProvider`
- Target URL: `process.env.OLLAMA_HOST` or `http://localhost:11434/api/generate`
- Request body: `{ model: options?.model || 'llama3.2', prompt: promptText, format: 'json', stream: false }`
- Uses `fetch` with `AbortSignal.timeout(options?.timeoutMs || 30000)`

- Parses response with `parseLLMJsonResponse`
</action>

</acceptance_criteria>
</task>

- Enforces 30s timeout
- Parses response text with `parseLLMJsonResponse`
</action>

<task id="03-02-T3">
<title>Implement unified LLMGateway dispatcher with 2-retry loop</title>
<read_first>
- backend/src/services/llm/types.ts
- backend/src/services/llm/ollamaProvider.ts
- backend/src/services/llm/geminiProvider.ts
</read_first>
<action>
Create `backend/src/services/llm/gateway.ts`:
- Export `LLMGateway` class
- Method `mapFields(providerName: 'ollama' | 'gemini', fields: FieldMetadata[], profile: UserProfile, options?: LLMOptions)`:
  - Instantiates `OllamaProvider` or `GeminiProvider` based on `providerName`
  - Runs retry loop (up to 2 retries on `LLMParseError`)
  - If retry succeeds, returns mappings
  - If all retries fail or `LLMProviderError` is thrown, rethrows actionable error for API response
</action>
<acceptance_criteria>
- `LLMGateway` routes calls to `OllamaProvider` or `GeminiProvider`
- Implements retry loop for malformed responses
- `npm run build -w backend` passes cleanly
</acceptance_criteria>
</task>
